# Poker Hand History Converter

A React-based web application that converts PokerStars hand history formats to be compatible with [CardsChat Replayer](https://www.cardschat.com/replayer).

## Features

- Converts PokerStars hand history text to CardsChat format
- Handles Seven Card Stud Hi-Lo game conversions
- Processes unknown card representations
- Adds street markers for better readability

## Usage

1. Paste your PokerStars hand history into the input field
2. View the converted format in real-time
3. Copy the converted text to use with CardsChat Replayer



Built with React + TypeScript
